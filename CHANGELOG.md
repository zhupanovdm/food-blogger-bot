# Изменения

## Unreleased

- Модель сначала оценивает массу порций по фото, затем калории и БЖУ; точный вес
  не требуется, вместо вопросов возвращается оценка с допущениями.
- Исправления через редактирование подписей/уточнений и обычный текст к последнему
  приёму пищи за сутки. Категория по времени с приоритетом явного указания пользователя.
- Добавлена категория «Полдник» и проверка совместной передачи двух фото альбома.

- Недельный отчёт отправляется одним альбомом из трёх диаграмм с датами периода
  в общей подписи. Альбом сохраняется в очереди целиком до успешной отправки.

- Меню Telegram с командами today, week, goal, help; короткая справка и подсказка
  изменения цели через `/goal`.

- Все фото, команды и уточнения принимаются только от владельца дневника;
  отдельной настройки доступа тренера нет.

- Локальный Telegram-бот с OpenAI API, учётом фото, подписей и исправлений.
- Хранение дневника и очередей в SQLite, отчёты `/today` и `/week`.
- Три недельных диаграммы: калории с целью `/goal`, БЖУ, гликемическая нагрузка.
- Начальный справочник ГИ с источниками и явные отметки неизвестных значений.
