# Local Food Log Implementation Plan

**Goal:** локальный бот с OpenAI API для закрытой группы пользователя и тренера.
**Architecture:** один процесс, Telegram long polling, постоянная очередь SQLite,
структурированный ответ OpenAI и вычисление итогов в Python.
**Tech Stack:** Python 3.14, httpx, OpenAI SDK, Pydantic, SQLite, unittest.

Пользователь выбрал OpenAI API в текущем диалоге; дополнительное согласование
провайдера не требуется. Исполнение в текущей сессии, без push и публикации.
