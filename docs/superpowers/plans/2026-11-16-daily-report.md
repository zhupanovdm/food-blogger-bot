# Дневной альбом и общий доступ к отчётам

**Цель:** согласованный альбом из трёх дневных диаграмм, отчёты для всех участников,
изменение цели и дневника только владельцем. Выпуск v1.0.0 и локальный перезапуск
явно поручены пользователем 16.11.2026.

**Устройство:** расширить существующие дневные корзины Store списком приёмов,
не менять схему базы. Matplotlib получает текущий день и предыдущие семь дат.
Существующая очередь альбомов обеспечивает доставку трёх картинок одним запросом.
