# Ввод еды текстом и упрощение отчётов

Пользователь согласовал `/food описание` и поручил реализацию и выпуск 17.11.2026.

- `/food описание` создаёт отдельный приём пищи только от владельца в настроенной
  группе, даже если команда отправлена ответом. Время — дата исходного сообщения.
- Описание передаётся модели без фото. При отсутствии веса используется типичная
  порция с явным допущением. Не относящийся к еде текст не учитывается.
- Ответ на исходное сообщение/оценку и редактура исходного сообщения пересчитывают
  ту же запись. Повторные события не удваивают запись и не запускают лишний анализ.
- Пустая команда показывает пример. Команда добавляется в меню и справку.
- Обычный текст сохраняет поведение уточнений, без автоматического создания еды.
- `/week` содержит два графика: калории и БЖУ. `/today` сохраняет три графика.
  График, расчёты и справочник гликемической нагрузки удаляются. Новая схема
  ответа модели не содержит gi_key и available_carbs. Старые оценки остаются
  читаемыми, эти два поля отбрасываются при загрузке без изменения остальных полей.
- Проверки: доступ, время и категория, дубли, редактура, уточнения, ошибки модели,
  сохранение очереди после перезапуска, два недельных PNG и три дневных PNG.
- Релиз v1.1.0: feature push, merge main, тег на main, push main и тега.
  Запущенный процесс не останавливать: пользователь перезапустит сервер сам.
