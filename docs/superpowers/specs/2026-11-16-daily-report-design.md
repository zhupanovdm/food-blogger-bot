# Дневной графический отчёт и просмотр команд участниками

Дата: 2026-11-16. Статус: эскиз для согласования, сервис пока не изменён.

## Подтверждённые требования пользователя

- В настроенной закрытой группе любой участник может вызвать отчёт.
- `/goal` без параметра показывает текущую цель в ккал и пример `/goal 2200`.
- Устанавливать цель может только хозяин; для первой версии сохраняем существующую
  настройку владельца дневника TELEGRAM_OWNER_ID.
- `/today` должен стать изображением: калории, БЖУ, отдельные приёмы пищи,
  итог дня, остаток до цели, среднее за неделю.
- Приёмы пищи строго в хронологическом порядке по времени исходного сообщения,
  одноимённые категории не объединяются. Каждый приём показывает долю суточной цели.
- Сначала показать эскиз и получить согласование, только затем реализовывать.

## Предложенное представление

Один альбом из трёх PNG по последнему требованию пользователя:
1. Итог дня. Слева круговая диаграмма: если цель не превышена, полная окружность
   равна цели, два сектора — Сегодня/Остаток. Если превышена, полный круг равен
   фактическому суточному потреблению, сектора — «В пределах цели» и «Превышение».
   Превышение красным. Внутри каждого ккал; снаружи доли только до превышения цели.
   Справа сверху Сегодня, ниже цель и среднее за предыдущую неделю с периодом и покрытием.
2. Калории по отдельным приёмам пищи в хронологическом порядке, подписи времени
   и категории. Ккал над столбцами, доли суточной цели внутри столбцов без «цели».
3. Три столбца БЖУ для каждого приёма, тот же хронологический порядок. Итоги
   БЖУ за день указаны в компактной легенде.
Единицы и «≈ оценка» рядом с Y, без длинных пояснений на картинке.
Сохраняются «Сегодня» вместо «Съедено», «Остаток» вместо «Осталось» и единица
«ккал». Прежнее расположение цели последней в строке отменено: теперь она справа
сверху. Три изображения одинакового размера с едиными заголовками и полями.

Актуальные эскизы на условных данных: `docs/mockups/daily-summary-preview.png`,
`daily-meals-preview.png`, `daily-macros-preview.png`. Предыдущий общий PNG — старый вариант.
Генератор эскизов: `docs/mockups/build_daily_preview.py`. Сервис использует
`food_log.charts.render_daily_charts` по тем же правилам.

## Предложенные правила расчёта

- Доля приёма = его калории / текущая суточная цель × 100%.
- Остаток = цель − записанное потребление; при превышении показывать «Превышено»,
  а не отрицательный остаток. Если цель не задана, проценты/остаток не вычислять.
  По уточнению пользователя при превышении меняется знаменатель: круг равен
  потреблению, сектора цели и превышения суммируются в фактические ккал.
  Пример: цель 2200, потребление 2700 → сектора 2200 и красные 500 ккал.
  При превышении проценты у секторов не показывать. Под значением «Сегодня»
  на одной строке с «ккал» показывать процент потребления от цели (цель = 100%):
  в этом примере «ккал · 122,7% от цели».
  Справа над целью и средним всегда отдельный блок «Сегодня / значение / ккал»,
  тем же шрифтом и размером, что остальные показатели: зелёный при потреблении
  ниже или равном цели, красный при превышении. Строки под заголовком нет.
  Доли отдельных приёмов пищи
  на второй диаграмме по-прежнему вычисляются от цели, не от фактического потребления.
- Среднее: за 7 предыдущих календарных дней, исключая незавершённый текущий,
  только по дням с записями. Показывать период и число дней с записями из 7.
  Если данных нет, писать «нет данных», не ноль. Этот выбор входит в согласование.
- Пропуски и незавершённые записи не становятся нулевыми значениями.
- Эскиз превышения: `docs/mockups/daily-summary-over-goal-preview.png`.

## Доступ

Внутри настроенной группы всем участникам доступны `/today`, `/week`, `/goal`
без параметра, `/help`. Изменение цели, фото и правки дневника — только владельцу.
Меню команд должно быть доступно группе. Чаты вне настроенной группы игнорируются.
`/whoami` остаётся служебной командой владельца вне меню.
